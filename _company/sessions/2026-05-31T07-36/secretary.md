### 📝 코다리 에이전트에게 전달할 지시사항 (Firebase 배포 준비)

**목표:** 사주 웹사이트를 Firebase를 사용하여 구축하고 운영하기 위한 초기 단계 작업 목록 및 기술 요구사항을 정리하여 배포 준비를 시작할 것.

**핵심 기술 스택:** Firebase (Hosting, Cloud Functions, Firestore)

#### 1. 초기 작업 목록 (Phase 1 Checklist)
*   **프로젝트 구조 분석:** 현재 프로젝트의 루트 디렉토리 구조(`package.json`, `firebase.json` 등)를 정확히 파악합니다.
*   **빌드 프로세스 검증:** `npm run build` 명령이 정상적으로 작동하여 빌드 아티팩트가 생성되는지 확인합니다.
*   **Firebase 설정 검토:** `firebase.json` 파일이 Hosting 배포에 필요한 디렉토리 구조 및 빌드 명령을 올바르게 정의하고 있는지 검토합니다.
*   **Cloud Function 설계:** 사주 계산 및 AI 로직(API 호출 포함)을 처리할 Cloud Functions의 초기 구조를 설계합니다.

#### 2. 기술적 요구사항 (Technical Requirements)
*   **데이터베이스 스키마:** Firestore에 저장할 사용자 데이터(사주 기록, 인증 정보 등)에 대한 초기 스키마 초안을 정의합니다.
*   **보안 설정:** Firebase Authentication 및 Firestore 보안 규칙(Security Rules)의 기본 설정 방향을 제시합니다.
*   **API 키 관리:** 외부 API 키(예: AI 엔진 키)는 코드에 하드코딩하지 않고, **Cloud Functions 환경 변수**를 통해 안전하게 관리하는 방안을 확립합니다.
*   **배포 전략:** Staging 환경에서 테스트 후 Production 환경으로의 단계적 배포 계획을 수립합니다.

#### 3. 코다리에게 요청하는 최종 액션
**"프로젝트 루트 디렉토리의 `package.json` 및 `firebase.json` 파일 내용을 확인하고, 이를 기반으로 Firebase Hosting 배포를 위한 초기 환경 설정 및 빌드 검증 계획을 제시하라."**
